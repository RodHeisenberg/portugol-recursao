# Missão Recursão

Atividade interativa criada para apoiar a **Aula 05 de Lógica de Programação**, com foco em **recursividade**.

A proposta é trabalhar o conteúdo de forma prática e progressiva, usando uma página HTML com desafios curtos e uma atividade final integrada ao **Portugol Web Studio**.

## Objetivos da atividade

Ao final da atividade, o aluno deverá ser capaz de:

- compreender o conceito de recursividade;
- identificar o caso base de uma função recursiva;
- reconhecer o passo recursivo;
- perceber quando uma chamada está se aproximando ou se afastando do caso base;
- diferenciar recursão de iteração;
- prever a saída de algoritmos recursivos simples;
- executar um código recursivo no Portugol Web Studio.

## Como funciona

A atividade possui **10 questões interativas**.

As questões começam com situações simples e aumentam gradualmente o nível de dificuldade.

Durante a atividade, o aluno trabalha com temas como:

1. chamada de uma função por ela mesma;
2. condição de parada;
3. identificação do caso base;
4. fatorial;
5. ordem das chamadas e retornos;
6. soma recursiva;
7. aproximação do caso base;
8. recursão x iteração;
9. previsão de resultados;
10. identificação de erros em funções recursivas.

Cada questão oferece feedback imediato e uma dica caso o aluno tenha dificuldade.

## Atividade final

Depois das 10 questões, o aluno chega ao **Laboratório Final**.

Nessa etapa, a página gera um código em Portugol.

O aluno deverá:

1. copiar o código exibido na página;
2. acessar o [Portugol Web Studio](https://portugol.dev/);
3. colar o código;
4. executar o programa;
5. observar o resultado apresentado;
6. voltar para a página da atividade;
7. informar o resultado correto;
8. validar a resposta.

A missão só é concluída quando o resultado informado estiver correto.

## Tempo estimado

A atividade foi planejada para aproximadamente **25 a 30 minutos**.

Ela pode ser utilizada:

- durante uma aula ao vivo;
- como atividade guiada pelo professor;
- em pequenos grupos;
- individualmente;
- como revisão após a explicação do conteúdo.

## Uso em aula

Uma sugestão de aplicação é:

- apresentar brevemente o conceito de recursividade;
- deixar os alunos avançarem pelas questões;
- interromper em alguns pontos para discutir as respostas;
- realizar o laboratório final em conjunto;
- finalizar comparando recursão e iteração.

A atividade funciona especialmente bem em aulas online, pois o aluno não precisa instalar nenhum software para realizar as questões.

O único ambiente externo utilizado na etapa final é o Portugol Web Studio.

## Como executar localmente

Basta abrir o arquivo:

```text
index.html
```

em qualquer navegador moderno.

Não é necessário servidor local.

## Como publicar no GitHub Pages

1. Crie um repositório no GitHub.
2. Envie o arquivo da atividade com o nome:

```text
index.html
```

3. Acesse:

```text
Settings > Pages
```

4. Em **Build and deployment**, escolha:

```text
Deploy from a branch
```

5. Selecione:

```text
Branch: main
Folder: / (root)
```

6. Salve as alterações.

Depois de alguns instantes, o GitHub disponibilizará a atividade em um endereço semelhante a:

```text
https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/
```

## Observação

A atividade foi pensada como material didático para introdução à recursividade.

O foco não é aprofundar conceitos de pilha de execução ou otimização, mas ajudar o aluno a compreender visualmente três ideias fundamentais:

```text
1. Existe uma condição de parada?
2. O problema fica menor a cada chamada?
3. A chamada está se aproximando do caso base?
```
